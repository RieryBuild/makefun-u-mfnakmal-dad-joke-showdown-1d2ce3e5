One original dad joke, told at the breakfast table: a daughter asks why Dad butters his toast on both sides, and Dad's answer lands the pun at the very end. The program writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) — 104 characters, plain UTF-8, stdlib only, fully deterministic.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
cat output/entry.txt
```
